---
title: What is iCE Studio?
weight: 1
---

**iCE Studio** is a visual FPGA design tool that lets you create digital circuits by connecting blocks instead of writing verilog code. 

Designed for beginners, it provides drag-and-drop interface for building, simulating, and programming FPGA designs.

![iCE Studio](images/ice-studio.png)

With iCE Studio, you can focus on understanding digital logic and hardware concepts without worrying about HDL syntax. As you gain confidence, you can gradually transition to writing Verilog and exploring more advanced FPGA workflows.

For more information, visit the [iCEStudio Documentation ↗](https://icestudio.readthedocs.io/en/latest/).
