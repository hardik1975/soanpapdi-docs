### 8-Bit Counter

A counter is one of the fundamental building blocks of digital systems.

This example shows how an FPGA can count events and display the result using LEDs, helping you understand concepts such as clocks, registers, and sequential logic.

## Keep Exploring

These examples are just the beginning. Try modifying them, combining multiple blocks, and experimenting with different peripherals to learn how FPGA-based systems are built.

The best way to learn FPGA development is by building and experimenting.
